# Data and code availability — text for the manuscript

**Data availability.** The per-crown leaf-presence time series of the 23,163 automatically delineated
and 969 field-identified crowns, the crown polygons, the metrics of leaf loss, the species and leaf
habit of the field-identified crowns, their terrain descriptors, the daily climate series, the labels
and DINOv2 features of the 199,681 photo-interpreted points, and a document showing the
leaf-presence probability map of every acquisition (27 at Luki, 46 at Mbalmayo, 44 at Yangambi) are
stored in the University of Liège data repository and are available from the corresponding author on request. The UAV
orthomosaics and the full-resolution probability maps are available through the Canopy Observatories
network (CanObs, https://www.canobs.net) upon request.

**Code availability.** The code of the processing chain (DINOv2 feature extraction, leaf-presence
model, probability maps, per-crown time series) and of all analyses, together with the fitted
leaf-presence model, is available at https://github.com/APlumacker/canopy-deciduousness under an MIT
licence. Running the analysis scripts on these data reproduces the figures and tables of the article.
